# Corpus sources

Each `.txt` note in this folder is a short summary **written in our own words** (no copied text).
The first three lines of each note hold its `Title`, `URL` and `Org`. The doc id is the file name without `.txt`.

**URL status** (re-checked 2026-11-27: every link was opened and the page title matched the organisation):
- **OK**: the organisation's site loads. Most links are home pages, so the exact page still has to be found.
- In Nov 2026 we replaced links that no longer worked: four ICAR `*.icar.gov.in` sites, TNAU Agritech and the IRRI
  Knowledge Bank did not load at all, `plantwise.org` now redirects to cabi.org, and `rkmp.co.in` now belongs to an
  unrelated website. Where the same organisation has a working site we use it; otherwise the note now points to
  another authoritative organisation that publishes the same advice.
- **VERIFY content**: the notes are our own summaries of commonly published IPM advice; open each link and paste the
  exact supporting page (IPM package, advisory, bulletin) into the note header before submission.

> Most URLs point to the organisation's home page. Before submission, open each site, find the exact page
> (IPM package, advisory or bulletin) that supports the note, and paste that deeper link into the note header.
> Threshold numbers (ETLs) and variety names in the notes are commonly published values; cross-check them with
> the latest local package of practices (e.g. UAS / state agriculture department in India, national extension elsewhere).
